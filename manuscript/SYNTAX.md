# Manuscript syntax reference (GoldenEye: ARKANGEL)

This file documents the token and figure syntax. It is a *reference*: sections
that render must only use tokens produced by `generate_variables()`, enforced
by `tests/test_manuscript_variables.py::test_all_manuscript_tokens_are_generated`.

## Manuscript tokens

Numeric values that come from analysis **must** use double-brace variables —
never hardcode a number that changes when `config.yaml` or the scenario is
edited. The full token map is the return value of
`src/goldeneye/manuscript_variables.py::generate_variables()`.

| Token | Meaning |

| `{{GE_IDENTITY}}` | Film identity (GOLDENEYE) |
| `{{GE_CODENAME}}` | Mission codename (ARKANGEL) |

## Adding a token

1. Add a key/value to `generate_variables()` in `src/goldeneye/manuscript_variables.py`.
2. Reference it in a numbered section as `{{NAME}}`.
3. The live cross-reference test fails if any numbered-section token is missing.
