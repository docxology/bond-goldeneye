# manuscript/

Technical manuscript for the GoldenEye: ARKANGEL BOND film package. The
numbered sections are rendered with token substitution by
`scripts/z_generate_manuscript_variables.py` into `output/manuscript/`.

Quick reference: `config.yaml` holds the paper identity and scenario
parameters; `SYNTAX.md` documents token and figure syntax; `references.bib`
holds the bibliography for the EMP and dam-break citations.
