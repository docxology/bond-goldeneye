# scripts/

Thin per-phase CLIs for the ARKANGEL mission (GoldenEye). Full disclosure in
`AGENTS.md`. Quick start from the package root:

```bash
uv run python scripts/brief.py
uv run python scripts/recon.py "assess the Arkangel facility"
uv run python scripts/plan.py
uv run python scripts/execute.py
uv run python scripts/debrief.py
uv run python scripts/z_generate_manuscript_variables.py
```
